# ZeroCode Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rewrite claw-code in Zig as a standalone Claude Code reimplementation with deterministic memory management that eliminates Node.js RSS bloat.

**Architecture:** Modular monolith with three-tier arena allocator strategy (persistent/session/turn). Single `build.zig`, all modules under `src/`. API-first design: get streaming working, then layer tools, MCP, plugins.

**Tech Stack:** Zig 0.15.2, std.http.Client/Server, std.json, Tree-sitter (C link), no other external deps.

**Spec:** `docs/superpowers/specs/2026-04-02-zerocode-design.md`

**Reference:** [instructkr/claw-code](https://github.com/instructkr/claw-code) Rust implementation. Follow its patterns when this plan is ambiguous.

**Existing code to reuse:** `~/LCC/src/` — terminal.zig, markdown.zig, json_helper.zig, history.zig provide a working foundation for terminal I/O, markdown rendering, JSON helpers, and input history.

### Zig 0.15.2 API Notes (CRITICAL — read before implementing)

These patterns differ from older Zig versions and MUST be followed:

1. **ArrayList initialization**: Use `.empty`, pass allocator to each method call:
   ```zig
   var list: std.ArrayList(u8) = .empty;
   try list.append(alloc, 'x');
   list.deinit(alloc);
   ```
   NOT `.init(alloc)` — that is the old API.

2. **JSON serialization**: `std.json.stringifyAlloc` does not exist. Use:
   ```zig
   const str = try std.json.stringifyAlloc(alloc, value, .{});
   // Actually in 0.15.2, use std.json.Stringify + Writer
   ```

3. **HashMap**: Use `std.StringHashMapUnmanaged(V)` with `.empty` and pass allocator to each call. Or use `std.StringHashMap(V)` with `.init(alloc)`.

4. **C source files in build.zig**:
   ```zig
   lib.root_module.addCSourceFile(.{ .file = b.path("path/to/file.c") });
   lib.root_module.addIncludePath(b.path("path/to/include"));
   ```

5. **build.zig.zon**: Run `cd ~/zerocode && zig init` first to get a valid fingerprint, then replace contents. Do NOT use `0x0` as fingerprint.

```zig
const std = @import("std");

pub fn build(b: *std.Build) void {
    const target = b.standardTargetOptions(.{});
    const optimize = b.standardOptimizeOption(.{});

    const exe = b.addExecutable(.{
        .name = "zerocode",
        .root_module = b.createModule(.{
            .root_source_file = b.path("src/main.zig"),
            .target = target,
            .optimize = optimize,
        }),
    });

    b.installArtifact(exe);

    const run_cmd = b.addRunArtifact(exe);
    run_cmd.step.dependOn(b.getInstallStep());
    if (b.args) |args| {
        run_cmd.addArgs(args);
    }

    const run_step = b.step("run", "Run ZeroCode");
    run_step.dependOn(&run_cmd.step);

    const exe_tests = b.addTest(.{
        .root_module = b.createModule(.{
            .root_source_file = b.path("src/main.zig"),
            .target = target,
            .optimize = optimize,
        }),
    });

    const test_step = b.step("test", "Run tests");
    test_step.dependOn(&b.addRunArtifact(exe_tests).step);
}
```

- [ ] **Step 2: Write conversation.zig**

The `runTurn` loop:
1. Add user message to session
2. Build MessageRequest
3. Send streaming request
4. Iterate StreamEvents → render text, track tool_use
5. If stop_reason == .tool_use and tool registry available: execute tools, add results, loop
6. **If tool_use but no matching tool: return tool_result with "Tool not found" error** (handles the case before tools are registered in later tasks)
7. Turn allocator `.free_all` on completion

Reference: claw-code `runtime/src/conversation.rs` (~26KB).

- [ ] **Step 3: Write full main.zig with arg parser, signal handler, REPL**

**Argument parser**: Manual parsing like LCC. Support flags: `--model`, `--continue`, `--resume`, `--system-prompt`, `--append-system-prompt`, `--permission-mode`, `--print`, `--mcp-config`, `--verbose`, `--version`, `--help`.

**Signal handler**: Set up SIGINT handler at startup. Uses atomic `interrupted` flag. Double Ctrl+C exits. Handler also sends SIGTERM to child processes via atomic PID. Streaming reader checks `interrupted` between chunks and aborts cleanly. Turn allocator `.free_all` runs even on interrupted turns.

**Three-tier allocator setup**:
```zig
var gpa: std.heap.GeneralPurposeAllocator(.{}) = .init;
const persistent = gpa.allocator();
var session_arena = std.heap.ArenaAllocator.init(std.heap.smp_allocator);
// turn_arena created fresh per turn, .free_all after each turn
```

**Non-interactive mode**: Detect `!std.posix.isatty(STDIN_FILENO)`. If piped, read all stdin, send as single message, print response, exit.

**REPL loop**: Read input → check `/` commands (stub for now) → `conversation.runTurn()` → turn arena free_all → loop.
