# zephwm Zig 0.16 Migration Design

**Date:** 2026-04-15
**Status:** Draft — awaiting Zig 0.16.0 release for compile-time verification
**Scope:** Migrate zephwm (`~/zephwm/`, v0.4.0, ~7,500 LOC) from Zig 0.15.2 to 0.16.0
**Reference:** https://ziglang.org/download/0.16.0/release-notes.html

## 1. Goals & Non-Goals

### Goals
- `zig build` passes cleanly on 0.16.0 for native (x86_64-linux) and cross (aarch64-linux-gnu) targets.
- `zig build test` passes all existing unit suites (tree / criteria / layout / config / command / ipc / workspace / scratchpad / builtin_status).
- All three binaries (zephwm / zephwm-msg / zephwm-bar) retain functional parity and within ±10% of current binary sizes (130KB / 27KB / 63KB aarch64).
- PSS on HackberryPi Zero remains at ~600KB (no regression).
- `@cImport` is fully eliminated in favor of build-system `addTranslateC`.

### Non-Goals
- New features or behavior changes.
- Refactoring beyond what the migration forces.
- Re-benchmarking or micro-optimization.
- Changes to the workspace `bar-visual-redesign` worktree (will be rebased separately by its owner).

## 2. Preconditions

- Zig 0.16.0 officially released and available via `archlinux-extra/zig` or `zigup fetch 0.16.0`.
- Working tree clean; new branch `zig-0.16-migration` cut from `main`.
- Tag `release/0.15.x` created on the pre-migration `main` HEAD for rollback.

## 4. Migration Details

### 4-A. `@cImport` → build.zig `addTranslateC` (full diff)

**Why:** `@cImport` is deprecated in 0.16. Per user decision, full removal for long-term maintainability.

**build.zig — add three translate-c steps before module creation:**

```zig
// XCB + XCB-RANDR header (for zephwm + bar; the bar additionally needs xcb_image)
const xcb_translate = b.addTranslateC(.{
    .root_source_file = b.path("src/xcb_cimport.h"),
    .target = target,
    .optimize = optimize,
});
if (sysroot_inc) |p| xcb_translate.addIncludePath(p);
const xcb_c_mod = xcb_translate.createModule();

// XCB + XCB image (bar-specific)
const xcb_image_translate = b.addTranslateC(.{
    .root_source_file = b.path("zephwm-bar/xcb_image_cimport.h"),
    .target = target,
    .optimize = optimize,
});
if (sysroot_inc) |p| xcb_image_translate.addIncludePath(p);
const xcb_image_c_mod = xcb_image_translate.createModule();

// builtin_status system headers (ioctl, wireless, time)
const sys_translate = b.addTranslateC(.{
    .root_source_file = b.path("zephwm-bar/sys_cimport.h"),
    .target = target,
    .optimize = optimize,
});
if (sysroot_inc) |p| sys_translate.addIncludePath(p);
const sys_c_mod = sys_translate.createModule();
```

Then attach via `.imports`:

```zig
// main zephwm_exe module
.imports = &.{
    .{ .name = "c", .module = xcb_c_mod },
},
// bar_exe module
.imports = &.{
    .{ .name = "c", .module = xcb_image_c_mod },
    // ...existing ipc/builtin_status...
},
// builtin_status_mod
.imports = &.{
    .{ .name = "c", .module = sys_c_mod },
},
```

**New header files to create (mirror current `@cImport` contents):**

- `src/xcb_cimport.h` — `#include <xcb/xcb.h>` + `<xcb/randr.h>` (exact set currently in `src/xcb.zig`)
- `zephwm-bar/xcb_image_cimport.h` — `#include <xcb/xcb.h>` + `<xcb/xcb_image.h>`
- `zephwm-bar/sys_cimport.h` — `#include <sys/ioctl.h>` + `<linux/if.h>` + `<time.h>` (exact set currently in `builtin_status.zig`)

**Source file changes:**

```zig
// src/xcb.zig:4 — BEFORE
pub const c = @cImport({
    @cInclude("xcb/xcb.h");
    @cInclude("xcb/randr.h");
});

// AFTER
pub const c = @import("c");
```

Same pattern for `zephwm-bar/main.zig:8` and `zephwm-bar/builtin_status.zig:3`.

### 4-B. `std.io.fixedBufferStream` → `std.Io.Writer.fixed` (full diff)

**Why:** `FixedBufferStream` removed in 0.16.

**Sites (12):** `src/main.zig` 197, 251, 304, 320, 345, 392, 409 (7 sites); `src/event.zig` 1178, 2118, 2170, 2762 (4 sites); `zephwm-bar/main.zig:745` (1 site).

```zig
// BEFORE (src/main.zig:197 pattern)
var fbs = std.io.fixedBufferStream(buf);
const w = fbs.writer();
std.fmt.format(w, "{{\"num\":{d},\"name\":\"", .{num}) catch return "[]";
// ... more writes ...
return fbs.getWritten();

// AFTER
var w = std.Io.Writer.fixed(buf);
w.print("{{\"num\":{d},\"name\":\"", .{num}) catch return "[]";
// ... more writes via w.print / w.writeAll ...
return w.buffered();
```

**Note (Risk 2.2):** The exact name `std.Io.Writer.fixed` is inferred from release notes phrasing. Confirm against the 0.16.0 std source at `lib/std/Io/Writer.zig` before committing. Fallback candidates: `std.Io.Writer.Fixed.init(buf)`, `std.Io.BufferedWriter.fixed(buf)`.

### 4-C. `std.fs.*` → `std.Io.Dir`/`std.Io.File` with Io propagation (full diff)

**Why:** `std.fs.Dir`/`File` relocated under `std.Io` with mandatory `io` parameter.

**Io propagation strategy (decision):** Thread an `std.Io` instance from each binary's `main()` through to all callers. Rationale: matches std's 0.16 design direction; enables future `std.Io.Mock` for tests; makes implicit dependencies explicit.

**Binary entry points — create Io once:**

```zig
// src/main.zig main(), zephwm-msg/main.zig main(), zephwm-bar/main.zig main()
pub fn main() !void {
    var gpa_impl = ... // existing
    const gpa = gpa_impl.allocator();

    var io_impl = std.Io.Threaded.init(gpa);
    defer io_impl.deinit();
    const io = io_impl.io();

    // ...existing setup, now with `io` available...
}
```

**`EventContext` (src/event.zig):** Add `io: std.Io` field; initialize from `main()`; pass through to any fs-touching helper.

**`builtin_status.zig` public API change:**

```zig
// BEFORE
pub fn getStatus(allocator: std.mem.Allocator, ...) !StatusLine { ... }

// AFTER
pub fn getStatus(io: std.Io, gpa: std.mem.Allocator, ...) !StatusLine { ... }
```

**Call site transforms (builtin_status.zig):**

```zig
// BEFORE
const file = std.fs.openFileAbsolute(path, .{}) catch return null;
var dir = std.fs.openDirAbsolute(base_path, .{ .iterate = true }) catch return null;
std.fs.accessAbsolute(check_path, .{}) catch continue;

// AFTER
const file = std.Io.Dir.openFileAbsolute(io, path, .{}) catch return null;
var dir = std.Io.Dir.openDirAbsolute(io, base_path, .{ .iterate = true }) catch return null;
std.Io.Dir.accessAbsolute(io, check_path, .{}) catch continue;
```

**Call site transforms (src/event.zig L2721-2722, /proc/self/exe resolution for restart):**

```zig
// BEFORE
var exe_buf: [std.fs.max_path_bytes]u8 = undefined;
const exe_path = std.fs.readLinkAbsolute("/proc/self/exe", &exe_buf) catch { ... };

// AFTER (verify names against 0.16 std)
var exe_buf: [std.Io.max_path_bytes]u8 = undefined;  // or std.fs.max_path_bytes may remain as a pure const
const exe_path = std.Io.Dir.readLinkAbsolute(io, "/proc/self/exe", &exe_buf) catch { ... };
```

Since this path runs inside event dispatch, `io` is sourced from the `EventContext.io` field added above.

**Call site transforms (src/main.zig config path discovery, 357/361/365/367/377/570/573/588):**

```zig
// BEFORE
if (std.fs.cwd().access(path_buf[0..len], .{})) |_| break :blk path_buf[0..len] else |_| {}
if (std.fs.cwd().openFile(config_path, .{})) |file| { ... }
std.fs.cwd().makePath(config_dir) catch break :blk false;
const file = std.fs.createFileAbsolute(config_path, .{}) catch break :blk false;

// AFTER (names inferred from release notes — verify against 0.16 std)
const cwd = std.Io.Dir.cwd(io);
if (cwd.access(path_buf[0..len], .{})) |_| break :blk path_buf[0..len] else |_| {}
if (cwd.openFile(config_path, .{})) |file| { ... }
cwd.makePath(config_dir) catch break :blk false;
const file = std.Io.Dir.createFileAbsolute(io, config_path, .{}) catch break :blk false;
```

### 4-D. `std.process.Child.init` → `std.process.spawn` (full diff)

**Why:** Child spawn API unified around `std.process.spawn(io, .{...})`.

**Single site:** `zephwm-bar/builtin_status.zig:331` (iwgetid fallback for SSID detection).

```zig
// BEFORE
var child = std.process.Child.init(argv, std.heap.page_allocator);
child.stdout_behavior = .Pipe;
child.stderr_behavior = .Ignore;
try child.spawn();
// ... read stdout ...
_ = try child.wait();

// AFTER
var child = try std.process.spawn(io, .{
    .argv = argv,
    .stdout_behavior = .Pipe,
    .stderr_behavior = .Ignore,
});
defer _ = child.wait(io) catch {};
// ... read stdout via io ...
```

**Side effect:** Removes the implicit `std.heap.page_allocator` dependency — cleaner.

### 4-E. `std.posix` survival audit (table + individual diffs)

Per release notes: "Most std.posix and std.os.windows medium-level functions" removed. Low-level primitives (syscall wrappers) expected to remain.

| Symbol | Used at | 0.16 expected status | Fallback if removed |
|--------|---------|----------------------|---------------------|
| `std.posix.fd_t`, `pid_t` | widespread | **keep** (type alias) | — |
| `std.posix.STDOUT_FILENO` | msg/main.zig | **keep** (constant) | — |
| `std.posix.AF`, `SOCK`, `SIG`, `F`, `O`, `AT` | widespread | **keep** (constant namespaces) | — |
| `std.posix.sockaddr.un` | ipc.zig | **keep** | — |
| `std.posix.open`, `close`, `read`, `write` | widespread | **keep** (raw syscall) | `std.posix.system.*` |
| `std.posix.pipe`, `fork`, `dup2`, `kill` | bar.zig, bar/main.zig | **keep** (raw syscall) | `std.posix.system.*` |
| `std.posix.fcntl` | bar/main.zig | **keep** | `std.posix.system.fcntl` |
| `std.posix.socket`, `bind`, `listen`, `accept` | ipc.zig | **keep** | `std.posix.system.*` |
| `std.posix.mkdirat`, `unlinkat` | ipc.zig, main.zig | **keep** (syscall-level) | `std.posix.system.*` |
| `std.posix.getenv` | 8 sites (main×6, msg×1, bar×1) | **AT RISK** — may move to `std.process.getEnvVar` | See note below |

**`getenv` fallback plan (blast radius: 8 sites):** If removed, replace with `std.c.getenv` (libc is linked in all three binaries) OR `std.process.getEnvVarOwned(io, ...)` for non-critical sites. For hot paths (IPC socket resolution at `src/ipc.zig`, `zephwm-bar/main.zig:182`, `zephwm-msg/main.zig:52`), stick with `std.c.getenv` to avoid allocation. Per-site classification: cold = HOME/XDG_CONFIG_HOME/ZEPHWM_RESTART (6 sites, allocation OK); hot = I3SOCK socket resolution (2 sites, use `std.c.getenv`).

### 4-G. `std.fmt` format specifier sweep (table)

| Specifier in current code | 0.16 status | Action |
|---------------------------|-------------|--------|
| `{d}` (integers) | unchanged | none |
| `{s}` (strings) | unchanged | none |
| `{}` on bool (`,\"focused\":{}`) | **may break** — 0.16 format changes for default spec | change to `{s}` with `if (b) "true" else "false"` ternary |
| `{d:0>2}` (padding) | unchanged | none |
| `{x}` / `{X}` (hex) | unchanged | none |
| `{any}` / `{?}` / `{!}` | **verify** — format-string overhaul hinted in release notes | grep codebase at adapt time; zephwm currently clean on `{any}`, `{?}`, `{!}` (2026-04-15 grep) but re-verify |

**Sites using `{}` on bool:** `src/main.zig:233, 490` — JSON boolean fields.

```zig
// BEFORE
std.fmt.format(w, "{},\"focused\":{}", .{ visible, focused }) catch return "[]";

// AFTER (safer across 0.16)
w.print(",\"focused\":{s}", .{if (con.is_focused) "true" else "false"}) catch return "[]";
```
