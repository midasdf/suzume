## Why this wave

Forms are the foundation of every interactive web page. Wave 22 confirmed Google.com JS init reach, but `<input>` / `<select>` / `<textarea>` state management still violates HTML §4.10:
- `input.value` is just a content-attribute reflection. No "dirty value flag", so `defaultValue` and `value` are *the same property*.
- `input.checked` / `input.defaultChecked` likely missing entirely.
- `select.value` getter exists but no setter, no `selectedIndex`, no `options` collection.
- `form.reset()` cannot work correctly without dirty flags.

This blocks every login form, search box, dropdown, and dynamic UI built with React/Vue/vanilla JS.

## Spec anchors (HTML Living Standard)

- §4.10.5.1 Common form control APIs — *value sanitization algorithm*, *dirty value flag*
- §4.10.5.2 Reset algorithm — clear dirty flags, restore default values
- §4.10.7 The select element — selectedIndex, options, value, type, add/remove
- §4.10.10 The option element — selected, defaultSelected, index, text
- §4.10.21.4 Resetting a form

## Architecture

Add **internal slots** on form control wrapper objects (kotori JS objects) using existing JS object property pattern (e.g. `_dirtyValue`, `_dirtyChecked`, `_value`, `_checked`):

```
input.value  getter:
  if (this._dirtyValue) return this._value
  else                  return this.getAttribute("value") ?? ""

input.value  setter:
  this._dirtyValue = true
  this._value = sanitize(newValue, this.type)

input.defaultValue  getter:
  return this.getAttribute("value") ?? ""

input.defaultValue  setter:
  this.setAttribute("value", newValue)
  // dirty flag NOT touched

input.checked  getter:
  if (this._dirtyChecked) return this._checked
  else                    return this.hasAttribute("checked")

input.checked  setter:
  this._dirtyChecked = true
  this._checked = Boolean(newValue)

input.defaultChecked  getter:
  return this.hasAttribute("checked")

input.defaultChecked  setter:
  if (newValue) this.setAttribute("checked", "")
  else          this.removeAttribute("checked")

form.reset():
  for each control in this.elements:
    control._dirtyValue = false
    control._dirtyChecked = false
    delete control._value
    delete control._checked
    if control is select:
      restore each option.selected = option.defaultSelected
  dispatch "reset" event (cancelable, bubbles)
```

For `<textarea>`: defaultValue == textContent at parse time. After `value` set, dirty flag separates them.

For `<select>`: `value` is derived from selectedness of options.
- `selectedIndex` getter: index of first selected option, or -1
- `selectedIndex` setter: clear all .selected, set option[i].selected = true
- `value` setter: find first option whose value == newValue, select it
- `options` live HTMLOptionsCollection (querySelectorAll("option"))
- `selectedOptions` live HTMLCollection (querySelectorAll("option:checked") or filter)

For `<option>`:
- `selected` getter: `_dirtySelected ? _selected : hasAttribute("selected")`
- `selected` setter: `_dirtySelected = true; _selected = bool; if select-one mode, deselect siblings`
- `defaultSelected` reflects "selected" attribute
- `index` returns position among select.options
- `text` returns label or textContent (whitespace-collapsed)
