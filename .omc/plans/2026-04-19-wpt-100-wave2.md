## Principles (applies to every action in this wave)

1. **Spec-first** — every change cites its ECMA-262 / WHATWG DOM / CSS / HTML section. No "make this test pass" patches.
2. **Independent-file parallelism** — concurrency = min-cut of file ownership. (Not exercised in iteration 3's scope: single-file coding layer.)
3. **Root-cause over symptom** — 1D.1 Task 11 has been reverted twice for symptomatic reasons. This wave demands the post-mortem before the third attempt.
4. **Verify-before-complete** — Verification Sweep is a first-class deliverable, not an afterthought.
5. **Zero-regression** — sentinel suite gate at wave close; any drop halts merge.
6. **Memory-aware** — RPi Zero 2W ceiling (~5 MB binary, 512 MB RAM). Polyfill deletion is a binary-size credit; hard floor ≤ −5 KB if Task 11 proceeds (aspirational target: ≤ −10 KB).
